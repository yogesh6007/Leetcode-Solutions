## 📈 Problem-Solving Philosophy

> Don't memorize solutions.
> Understand the pattern behind them.

For every problem, I try to identify:

1. What is the brute-force approach?
2. What is causing the inefficiency?
3. Which data structure or algorithm can improve it?
4. What is the time and space complexity?
5. Can the solution be optimized further?
